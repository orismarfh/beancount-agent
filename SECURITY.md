# Segurança

Este repositório é público e contém apenas código, plano de contas de referência e dados sintéticos.

**Nunca faça commit de:** extratos bancários, faturas de cartão, livros contábeis reais, chaves de API, tokens ou qualquer credencial.
Esses dados ficam em um repositório privado separado.

Se algo sensível for commitado por engano, trate como vazado: revogue a credencial e avise o mantenedor imediatamente (não basta apagar o arquivo, o histórico do git mantém o conteúdo).

Para reportar uma vulnerabilidade, use o recurso "Report a vulnerability" na aba Security do repositório, sem detalhes em issues públicas.
