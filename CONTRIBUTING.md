# Contribuindo

1. `uv sync`
2. Crie uma branch a partir de `main` e faça commits pequenos.
3. Antes do PR: `uv run ruff check .` e `uv run pytest` devem passar.
4. Abra o PR para `main`.

Regra de ouro: este repositório é **público**. Use apenas dados 100% fictícios em exemplos e testes.
Nunca inclua extratos, faturas, livros reais, nomes de clientes ou credenciais.
